# Практическая работа 1

Тема: HTML и базовая CSS-разметка
Дисциплина: Технологии разработки программного обеспечения

## О проекте

Это одностраничный сайт курса, сделанный на HTML и CSS, JavaScript я не использовал
На странице есть шапка с меню, раздел "О курсе", шесть карточек, таблица, форма регистрации и подвал(footer)

## Как запустить

Скачать проект и открыть файл index.html в браузере

## Структура проекта

- index.html - сама страница
- styles.css - стили
- data/content.csv - данные для карточек и таблицы
- data/navigation.json - пункты меню
- README.md - этот файл с объяснением

## Структура HTML

Вверху страницы тег header, в нём название и меню nav
В main четыре раздела section с id about, tracks, schedule и signup, ссылки в меню ведут на эти id
В разделе tracks шесть карточек article, у всех одинаковая структура и класс card
В разделе schedule таблица с thead и tbody, в ней шесть строк
В разделе signup форма с полями для имени, email, возраста, списком направлений и комментарием, у каждого поля есть label
Внизу страницы footer
Заголовки идут по порядку: один h1, потом h2, потом h3

## Что использовано в CSS

- box-sizing: border-box для всех элементов
- общий шрифт, цвет и межстрочный интервал
- класс container, чтобы содержимое было по центру и не растягивалось
- оформление ссылок, кнопки и полей формы
- :hover для ссылок и :focus для полей, чтобы было видно, где курсор при нажатии Tab
- Flexbox в шапке и в карточках, карточки переносятся на новую строку при уменьшении окна
- таблица с рамками, а в обёртке table-wrapper есть прокрутка, чтобы на телефоне таблица не вылезала за экран
- медиазапрос для ширины до 720px, в нём меню встаёт в столбик и уменьшается заголовок

## Какие файлы из dataset использовались

- navigation.json: из него взяты пункты меню, поле label стало текстом ссылки, а target стал id раздела
- content.csv: значения title, category, description и value я перенёс вручную в карточки и в таблицу, а названия из title добавил в список направлений в форме

Картинки из dataset я не подключал
